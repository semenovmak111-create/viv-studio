# VIV Studio — сайт студии лазерной эпиляции и косметологии

Одностраничный лендинг (HTML + CSS + чистый JS, без сборки и зависимостей).
Открывается двойным кликом по `index.html` или заливается на любой хостинг как есть.

```
index.html      разметка и весь контент
css/style.css   дизайн-система (тёплая палитра, типографика, адаптив)
js/script.js    меню, табы прайса, маска телефона, отправка формы, анимации
images/         сюда положите фотографии студии
```

## Что уже настроено

- **Оффер 4U** в первом экране + блок отработки страхов и FAQ.
- **Реальные данные**: прайс с сайта студии, телефон, адрес, рейтинг 5,0 и отзывы с Яндекс Карт.
- **Форма записи** без бэкенда: собирает имя, телефон и услугу и открывает WhatsApp
  мастера с готовым сообщением. Чтобы отправлять заявки на почту/в CRM — замените
  блок `form.addEventListener('submit', …)` в `js/script.js` на запрос к вашему обработчику.
- **Адаптив** от 375 px, мобильная панель «Позвонить / Записаться», доступность
  (фокус-стили, aria-атрибуты, поддержка `prefers-reduced-motion`).

## Что стоит доделать перед публикацией

1. **Фотографии.** В первом экране стоит стилизованная заглушка — блок `.hero-photo`
   в `index.html`. Замените его на `<img src="images/studio.jpg" alt="Кабинет VIV Studio">`.
   Хорошо зайдут: кабинет, аппарат, мастер за работой, детали интерьера.
2. **Адрес.** На старом сайте указан офис 409, в карточке Яндекс Карт — этаж 2, офис 204.
   Проверьте и поправьте в двух местах: секция «Контакты» и подвал.
3. **Часы работы.** Не указаны ни на сайте, ни в открытых источниках — добавьте
   в блок «Контакты», это снимает лишние вопросы у клиента.
4. **Юрлицо и документы.** Для медицинских услуг обычно добавляют реквизиты,
   номер лицензии и политику обработки персональных данных (ссылка у чекбокса в форме).
5. **Аналитика.** Вставьте счётчик Яндекс Метрики перед `</body>` и настройте цели
   на клик по кнопкам записи и мессенджерам.
